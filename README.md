# Travel together

A private, two-person travel tracker built with PHP and SQLite. Each traveler can mark the ISO 3166-1 alpha-2 destinations they have visited; shared visits are highlighted automatically.

The interactive, dark-mode world map highlights each traveler's visits and places visited together. Map boundaries are bundled locally, so the map does not contact an external service.

AI was used to built this website.

## Requirements

- PHP 8.1 or later
- PDO SQLite enabled
- A web server with PHP support, or PHP's built-in development server
